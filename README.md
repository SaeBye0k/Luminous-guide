## 루미너스 가이드

루미너스 가이드는 게임 정보를 일방적으로 보여주는 위키를 넘어, 모험가들이 직접 평가와 경험을 더해 가는 참여형 공략 사이트입니다.

어떤 무기가 좋은지, 어떤 직업이 나와 맞는지 고민될 때 다른 모험가들의 평가를 확인할 수 있습니다. 직접 사용해 본 장비와 직업에는 티어를 투표하고, 자신만의 노하우는 공략 게시판에 남길 수 있습니다.

## 주요 기능

- **패치노트** — 최신 변경 요약을 읽고 좋아요·아쉬워요 평가와 댓글을 남길 수 있습니다.
- **게임 데이터베이스** — 무기, 직업, 유물의 등급·속성·설명과 이미지를 탐색할 수 있습니다.
- **커뮤니티 티어** — 로그인한 모험가의 S~F 투표를 모아 평균 점수, 분포, 의견 일치도를 보여줍니다.
- **최근 커뮤니티 픽** — 최근 투표를 받은 무기와 직업을 순환해서 소개합니다.
- **계정당 한 표** — 같은 버전과 항목에는 계정당 한 표만 반영되며, 선택을 바꾸면 기존 표가 갱신됩니다.
- **던전 공략** — 던전별 공략과 한줄평을 모아 보고, 렙업용·무기파밍·유물파밍·봉우리 파밍 태그로 공략을 찾을 수 있습니다.
- **공략 게시판** — 자신만의 공략을 작성하고 다른 모험가와 댓글로 의견을 나눌 수 있습니다.
- **개인 티어표** — 카드를 직접 배치해 나만의 티어표를 만들고 브라우저에 저장할 수 있습니다.
- **버전별 기록** — 패치 버전마다 투표를 분리해 현재 환경에 맞는 평가를 확인할 수 있습니다.
- **모험가 닉네임** — Xbox 로그인 후 설정한 닉네임으로 댓글과 공략 활동을 할 수 있습니다.

## 현재 수록 데이터

공개된 루미너스 RPG 자료를 바탕으로 완성된 데이터만 선별해 등록했습니다.

| 분류 | 수록 항목 | 표시 정보 |
| --- | ---: | --- |
| 무기 | 61개 | 이미지, 이름, 무기 등급, 속성, 설명 |
| 유물 | 56개 | 이미지, 이름, 희귀도, 속성, 설명 |
| 직업 | 55개 | 클래스 아이콘, 이름, 역할, 속성, 설명 |

현재 커뮤니티 평가 버전은 **[루미너스:윈더러스트]**입니다. `(미완)`, `(추가 전)` 또는 `(보류)`으로 표시된 자료는 정확한 정보 제공을 위해 제외했습니다.

## 커뮤니티 운영 원칙

- 커뮤니티 티어는 운영자의 임의 평가가 아니라 실제 사용자 투표로 만들어집니다.
- 아직 표를 받지 않은 항목은 임의의 등급 대신 **평가 대기**로 표시됩니다.
- 본인이 작성한 댓글과 공략은 직접 삭제할 수 있습니다.
- 장비 이름과 이미지 같은 공식 데이터는 저장소 관리자만 수정할 수 있습니다.
- 패치가 적용되면 새 버전의 투표를 시작하고 이전 기록은 구분해 보존합니다.

## 패치노트 등록

기존 Supabase 댓글 설정(`supabase/nickname-comments.sql`)을 사용합니다.
`supabase/patch-notes.sql`을 SQL Editor에서 실행한 뒤, 파일 하단의 등록 템플릿에 실제 패치 내용을 넣어 별도로 실행하세요.
최신 날짜의 패치가 메인에 표시되고, 패치노트 탭에서 이전 패치를 선택할 수 있습니다.
패치 등록은 SQL Editor에서 관리하며, 로그인한 사용자는 패치당 한 표를 남기고 자신의 평가를 변경할 수 있습니다.

## 던전 공략 태그

기존 게시판 스키마 적용 후 `supabase/dungeon-guides.sql`을 한 번 실행합니다.
`/dungeon-guides/`에서 던전을 선택해 공략과 한줄평을 확인합니다. 기존 던전 상세창과 같은 데이터를 사용하며, 공략 태그는 여러 개 선택할 수 있습니다.

`supabase/dungeon-guide-tag-counts.sql`은 공개 공략의 태그를 던전별로 집계합니다.
던전 카드에는 실제 공략에 붙은 태그만 표시되며, 작성·삭제 후 다시 집계합니다. 공략이 없는 던전에는 태그를 표시하지 않습니다.

던전 공략의 선택형 아이템 빌드 첨부에는 `supabase/guide-item-build.sql`을 한 번 적용합니다. 공략 작성 시 직업·갑옷·특성·6칸 인벤토리·초월 구성을 함께 저장하며, 빌드를 첨부하지 않고도 공략을 등록할 수 있습니다.
